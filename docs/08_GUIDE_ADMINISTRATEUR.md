# 8. Guide administrateur

Le Super Admin gère les comptes et rôles, l’identité KIN-MART, les taux USD/CDF, règles de fidélité, seuils Analytics, zones de livraison, sauvegardes et audit.

## Bonnes pratiques
- un compte individuel par employé ;
- désactiver le compte d’un employé sortant ;
- vérifier l’audit après une annulation importante ;
- sauvegarder avant import massif ou changement de prix ;
- conserver une copie des sauvegardes sur un support externe ;
- actualiser quotidiennement le taux de change si la politique du magasin l’exige.
