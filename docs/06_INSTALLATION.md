# 6. Installation

Voir `INSTALLATION.txt`. L’installation cible est `C:\xampp\htdocs\KinMart` avec base `kinmart`.

Les paramètres MySQL sont centralisés dans `app/config/config.php`. Le port n’est jamais dispersé dans les modèles.

`kinmart.sql` contient la structure et les données indispensables. `seed.sql` est facultatif et sert aux démonstrations.
